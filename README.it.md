# Portfolio

Portfolio personale di Claudio Giasi, AI Full-Stack Developer a Napoli. Un sito a pagina singola in stile fumetto stampato, in italiano e in inglese.

Il sito è in costruzione.

## Stack

React 19, TypeScript e Vite. Pubblicato su Vercel.

## Avvio in locale

Serve Node.js 22 o successivo.

```
npm install
npm run dev
```

Altri script: `npm run build`, `npm run lint`, `npm run typecheck`.
